Report Builder

Combine sheets into one master sheet and a summary. Works offline. Your files stay on this computer.

1

Load your files

Excel (.xlsx, .xlsm, .xls) or CSV. Add as many files as you need; every sheet is read.

2

Master sheet columns

Columns with the same name across sheets are combined automatically. Rename, reorder, combine, or exclude them here.

2b

Connected lists

Each list stays separate. Master rows are matched against it — by exact value or by a number embedded in the text, e.g. “PRODUCT RELATED SERV (344140)” matches group 344140 — and get a match-count column.

3

Summary

The summary always includes a report overview, record counts by source, key figures and data checks. Add breakdowns below; suggested ones are filled in for you.

4

Preview & export

Check the result, then download the formatted Excel report.
