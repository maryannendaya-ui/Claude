Mask Kit

Mask confidential data before sharing it — then restore the real values in whatever comes back. Works offline; nothing leaves this computer.

1

Mask files

Load the confidential files. The same value always gets the same mask, across all files, so lookups and connections still work on the masked data. Codes stay numeric (same number of digits), so group/vendor/material keys remain joinable.

2

Unmask results

Load the key file from step 1, then the processed files that came back. Every mask token and remapped code found in them is replaced with the original value. Excel formatting is preserved.

i

How to use this safely

  • Keep the key file. It is the only way back from masked to real values. It never needs to be shared — do not send it along with the masked files.
  • Masked files are safe to share for processing (e.g. building a report): names become tokens like VENDOR_0042, codes become different numbers with the same shape, and relationships between files are preserved.
  • Check the preview (sample column on the left) before sharing — set any column that should not leave at all to Blank, and columns that are harmless to Keep.
  • Amounts and dates are kept by default (reports usually need them). Set them to Blank if they are themselves confidential.
  • Tell whoever processes the data to keep tokens exactly as they are (not translate or reformat them) so unmasking can find them.
  • Unmasking replaces tokens and remapped codes wherever they appear — in cells, inside sentences, and in joined lists. A rare clash is possible if a computed number in the report coincides with a remapped code; the unmask report shows how many replacements were made per file so you can sanity-check.
